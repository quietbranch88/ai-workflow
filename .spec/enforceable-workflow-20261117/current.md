# Enforceable workflow improvements

## Goal

As the workflow owner, adopt evidence-driven safeguards, scoped API constraints,
document pruning, proportional verification and optional formal methods.

## Acceptance criteria

- [ ] AC-1: All five practices have actionable triggers and evidence limits.
  - Observable: guidance preserves authorization, real-boundary checks and required context; no universal API ban, deletion quota or token ratio.
  - Environment: canonical Markdown and packaged Claude adapters.
  - Verify: ten scoped fresh reviews and existing document/adapter contract tests.
- [ ] AC-2: Canonical changes reach mirrors without changing runtime tools.
  - Observable: mirrors agree and plugin source version advances; no installed rules or memory are changed.
  - Environment: isolated feature worktree.
  - Verify: repository suite, package validation and diff review.

## Non-goals

No product API implementation, formal model execution, global rule edits, automatic
usage collection, publication, merge or installation in this task.
